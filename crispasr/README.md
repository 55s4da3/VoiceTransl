# CrispASR

Download CrispASR from <https://github.com/CrispStrobe/CrispASR/releases>.

Place `crispasr.exe`, its runtime DLLs, the speech-recognition `.gguf`, and the forced-aligner `.gguf` in this directory. The application discovers those files automatically.

For a packaged build, create the `crispasr` directory beside `VoiceTransl.exe` so models and binaries remain independently replaceable.
